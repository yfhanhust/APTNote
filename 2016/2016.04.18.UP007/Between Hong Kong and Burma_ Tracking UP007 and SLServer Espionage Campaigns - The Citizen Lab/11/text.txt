On VirusTotal we discovered a file named javaupdata.dll (MD5: <7332245f67b6b8a256ab22a6496b4536), which
exports a function by the same name. Strings in the SLServer sample also reference a file by this name. When executed,

safetyssl.security-centers[.]com. Interestingly, while the 210.61.12[.]153 host did not respond to the SLServer
connections during analysis time, the host did accept the SSL connections from javaupdata.dll. Further analysis of this
file is ongoing.
