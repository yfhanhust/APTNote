


Sentence : Jailbreak Persistence
Once the kernel has been exploited, both exploits perform similar tasks to prepare the system to be jailbroken:


Disable kernel security protections including code signing


Remount the system partition


Clear the Safari caches (to help cover their tracks)


Write the jailbreak files (including the main loader as /sbin/mount_nfs)
To gain persistence, Pegasus replaces the system daemon rtbuddyd with a copy of the jsc binary and creates a link to a
script that is similar to the exploit for CVE-2016-4655, which we will describe later.
As a final step, the exploit removes /etc/nfs.conf which triggers the file to load /sbin/mount_nfs (which is the stage 3 jail
break loader). Because /sbin/mount_nfs is run as root, the code is run with full privileges.
