This is a graph representation of the world, where each node represents a country and edges represent that these countries are part of the world. I want to add attributes such as population, GDP, area, and capital city to each node (country). How can I do this in Python using NetworkX?
Certainly! You can use the `NetworkX` library in Python to create and manipulate graph structures. To add attributes like population, GDP, area, and capital city to each country node, you can follow these steps:

1. Install NetworkX if you haven't already:
   ```bash
   pip install networkx
   ```

2. Create the graph and add nodes with attributes.

Here's a complete example:

```python
import networkx as nx

# Create an empty directed graph
G = nx.DiGraph()

# List of countries with their attributes (example data)
countries_data = {
    'USA': {'population': 331002651, 'gdp': 2137108409900, 'area': 9372610, 'capital_city': 'Washington, D.C.'},
    'Canada': {'population': 37742154, 'gdp': 1647000000000, 'area': 9984670, 'capital_city': 'Ottawa'},
    'China': {'population': 1439323776, 'gdp': 14342955000000, 'area': 9596960, 'capital_city': 'Beijing'},
    # Add more countries and their attributes as needed
}

# Add nodes with attributes to the graph
for country, data in countries_data.items():
    G.add_node(country, **data)

# Add edges to represent that these countries are part of the world
for country in countries_data:
    G.add_edge('World', country)

# Example: Accessing node attributes
print(G.nodes['USA'])
print(G.nodes['Canada'])

# Example: Listing all nodes with their attributes
for node, attrs in G.nodes(data=True):
    print(f"Country: {node}, Attributes: {attrs}")

# Visualize the graph (optional)
import matplotlib.pyplot as plt

# Draw the graph
pos = nx.spring_layout(G)  # positions for all nodes
nx.draw(G, pos, with_labels=True, node_color='lightblue', font_size=10, font_weight='bold')
node_labels = {node: f"{data['population']}\n{data['gdp']}\n{data['area']}\n{data['capital_city']}" for node, data in G.nodes(data=True)}
nx.draw_networkx_labels(G, pos, labels=node_labels, font_size=8)
plt.show()
```

### Explanation:
1. **Graph Creation**: We create an empty directed graph using `nx.DiGraph()`.
2. **Node Addition with Attributes**: We define a dictionary `countries_data` where each key is a country name and the value is another dictionary containing attributes like population, GDP, area, and capital city. We then add these nodes to the graph along with their attributes using a loop.
3. **Edge Addition**: We add edges from a "World" node to each country node to represent that these countries are part of the world.
4. **Accessing Node Attributes**: You can access the attributes of any node using `G.nodes[<node_name>]`.
5. **Listing All Nodes with Attributes**: A loop is used to print all nodes and their attributes.
6. **Visualization (Optional)**: We use `matplotlib` to visualize the graph, including labels for each node that show their attributes.

This example provides a basic structure for adding and accessing attributes in a NetworkX graph. You can expand this by adding more countries and attributes as needed.
