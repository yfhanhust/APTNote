C2 communication
For C2 communication, first, the trojan sends the victim's computer name, user name, a
separator "ZxxZ" and the Windows version pulled from the registry. The server responds
back with data in the format :".
Next, the malware requests the program data. The server sends back the data of the
Portable Executable effectively matching the pattern:ZxxZ. It then saves the file to %LOCALAPPDATA%\Debug\<program
name>.exe and tries to execute it.
Request sent to C2.
If the download is successful, the server sends back the request with the opcode DN-S
and, in case of a failure, the opcode RN_E in their response. Based on our analysis, the
opdoce DN-S means "download successful" and RN_E stands for run error. If failed, the
malware attempts to download the program data 225 times, and after that, it will launch
itself and exit.
