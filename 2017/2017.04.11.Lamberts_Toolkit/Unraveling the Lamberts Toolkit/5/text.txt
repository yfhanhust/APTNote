The only known sample of Black Lambert was dropped by a TTF-exploit zero day (CVE-20144148). Its internal configuration included a proxy server which suggests the malware was created
to work in a very specific network configuration, inside the victim’s network.
An internal description of Black Lambert indicates what appears to be a set of markers used by
the attackers to denote this particular branch: toolType=wl, build=132914, versionName =
2.0.0 .
