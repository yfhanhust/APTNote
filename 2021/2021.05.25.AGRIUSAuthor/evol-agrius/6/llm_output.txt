### **Agrius: From Wipers to Ransomware**

#### **Overview**
The Agrius group, a threat actor with potential ties to Iran, has been active in deploying both wiper malware and ransomware. This analysis provides a detailed examination of their tools, techniques, and infrastructure, highlighting the evolution from destructive wiper attacks to more financially motivated ransomware operations.

### **Apostle: The Evolution of Ransomware**

#### **Initial Wiper Activity**
- **Apostle as a Wiper**: Initially, Apostle was used as a wiper malware, designed to overwrite files with random data, making recovery impossible without backups.
- **Targeting**: Apostle has been deployed against targets in Israel and the United Arab Emirates (UAE), aligning with regional tensions.

#### **Transition to Ransomware**
- **Ransomware Features**: Over time, Apostle evolved to include ransomware features. The malware now encrypts files and demands a ransom for decryption.
- **Ransom Note**: The ransom note is customized and includes specific details about the victim's data, threatening to publish it online if the ransom is not paid.

#### **Technical Analysis**
- **Code Overlaps with IPsec Helper**: Apostle shares significant code overlaps with IPsec Helper, a backdoor used by Agrius. This suggests a shared development environment or team.
- **Self-Deletion Mechanism**: Both Apostle and IPsec Helper implement a `SelfDelete()` function to remove traces of the malware after execution.
- **Customization**: The ransom note includes placeholders for victim-specific information, indicating a level of customization in the attack.

### **DEADWOOD Wiper**

#### **Overview**
- **C++ Implementation**: DEADWOOD is a wiper malware written in C++ using the Boost libraries.
- **Service and Application Modes**: It can be executed as a Windows Service or a standalone application. Each mode attempts to execute the other, ensuring comprehensive coverage.

#### **Configuration and Execution**
- **Configuration File**: The malware operates based on a configuration file embedded within the executable. Newer versions encrypt this configuration using AES.
- **Trigger Mechanism**: A trigger file (`Microsoft.Help.dll.iso`) is created to initiate the wiping process at a specific timestamp, allowing for coordinated attacks across multiple machines.

#### **Wiping Process**
- **Overwriting Files**: DEADWOOD overwrites files with random data, making recovery impossible. Unlike ransomware, there is no decryption option.
- **Impact**: The impact can mimic ransomware but is irreversible without backups.

### **Agrius and Iranian Nexus**

#### **Technical Indicators**
- **Webshells**: Modified versions of ASPXSpy webshells have been uploaded from Iran and other Middle Eastern countries, suggesting a regional focus.
- **Infrastructure**: Agrius infrastructure has resolved to Iranian domains in the past, further indicating a potential link.

#### **Operational Context**
- **Regional Tensions**: The timing of attacks aligns with ongoing cyber conflicts between Israel and Iran, particularly targeting critical infrastructure.
- **Target Selection**: Confirmed targets include nation-owned critical facilities in the UAE, which have been previously targeted by suspected Iranian threat actors.

### **Shared Resources and Collaboration**

#### **DEADWOOD Usage**
- **Newer Variant**: The DEADWOOD variant used by Agrius is a newer version with additional obfuscations, suggesting access to the original source code or collaboration with the development team.
- **Secondary Choice**: The deployment of DEADWOOD followed an attempt to use Apostle, indicating it was not the primary choice. This suggests that Apostle is part of Agrius's in-house arsenal.

### **Conclusion**
Agrius demonstrates a sophisticated approach to cyber operations, evolving from destructive wiper attacks to more financially motivated ransomware campaigns. The group's tools and techniques show a high degree of customization and coordination, with potential ties to Iranian threat actors. Understanding the technical details and operational context of Agrius is crucial for developing effective defenses against their activities.
