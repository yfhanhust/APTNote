Stage three
The third stage, responsible for downloading the main payload(s) from DePriMon’s operators,
also implements some interesting techniques.
For C&C communication, it uses the Microsoft implementation of SSL/TLS, Secure Channel,
instead of common APIs like WinHTTP or WinInet. Its configuration is very complex, as is the way
the malware handles it. Finally, the authors have put significant effort into encryption, making the
DePriMon malware more difficult to analyze.
