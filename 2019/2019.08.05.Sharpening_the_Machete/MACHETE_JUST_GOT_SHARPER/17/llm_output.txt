### Overview of Machete Malware

**Machete** is a sophisticated malware targeting Venezuelan military personnel and organizations. This malware has evolved over time, incorporating various techniques for initial access, execution, persistence, defense evasion, credential access, discovery, command and control (C2), and exfiltration.

### Key Components and Files

1. **Initial Access and Execution:**
   - **Spearphishing Links (T1192):** Emails contain links to download a compressed file from an external server.
   - **Spearphishing Attachments (T1193):** Emails include zipped files with malicious contents.
   - **User Execution (T1204):** Users are tricked into opening links or attachments, which execute the first component of Machete.

2. **Persistence:**
   - **Scheduled Task (T1053):** Other components of Machete are executed by Windows Task Scheduler.
   - **Hidden Files and Directories (T1158):** Malware files and folders are hidden for persistence.
   - **Masquerading (T1036):** File and task names impersonate legitimate software like Google Chrome, Java, Dropbox, Adobe Reader, and Python executables.

3. **Defense Evasion:**
   - **Obfuscated Files or Information (T1027):** Python scripts are obfuscated.
   - **Software Packing (T1045):** Machete downloaders are UPX packed.

4. **Credential Access:**
   - **Private Keys (T1145):** Scans for key and certificate file extensions.
   - **Credentials in Files (T1081):** Exfiltrates files with stored credentials for several browsers.

5. **Discovery:**
   - **System Network Connections Discovery (T1049):** Uses `netsh` command to list nearby Wi-Fi networks.
   - **File and Directory Discovery (T1083):** Produces file listings for exfiltration.
   - **Process Discovery (T1057):** Enumerates running processes searching for browsers.
   - **Peripheral Device Discovery (T1120):** Detects newly inserted devices by listening for `WM_DEVICECHANGE` messages.
   - **Browser Bookmark Discovery (T1217):** Gathers browser data such as bookmarks.
   - **Application Window Discovery (T1010):** Reports window names along with keylogger information.

6. **Data Collection:**
   - **Clipboard Data (T1115):** Steals clipboard data by creating an overlapped window that listens to keyboard events.
   - **Data from Local System (T1005):** Searches the file system for files of interest.
   - **Data from Removable Media (T1025):** Copies files from newly inserted drives.
   - **Input Capture (T1056):** Logs keystrokes from the victim’s machine.
   - **Screen Capture (T1113):** Captures screenshots.

7. **Exfiltration:**
   - **Data Staged (T1074):** Files and logs are stored in a temporary folder, encrypted.
   - **Commonly Used Port (T1043):** Uses standard FTP and HTTP ports for communications.
   - **Fallback Channels (T1008):** Uses HTTP to exfiltrate documents if FTP is unavailable.
   - **Remote File Copy (T1105):** Downloads additional files for execution on the victim’s machine.
   - **Standard Application Layer Protocol (T1071):** Uses FTP and HTTP for C2.
   - **Automated Exfiltration (T1020):** Automatically exfiltrates collected files to remote servers.
   - **Data Compressed (T1002):** Compresses browser profile data as .zip files before exfiltration.
   - **Data Encrypted (T1022, T1041):** Encrypts data with AES and sometimes encodes it with base64 before transmission.
   - **Exfiltration Over Command and Control Channel (T1041):** Exfiltrates data over the same channel used for C&C.
   - **Exfiltration Over Physical Medium (T1052):** Copies data from all drives to a removable drive if a special file is present.
   - **Scheduled Transfer (T1029):** Sends data to the C&C server every 10 minutes.

### Conclusion

Machete is a highly sophisticated malware that employs a wide range of techniques to gain initial access, execute, persist, evade defenses, access credentials, discover information, collect data, and exfiltrate it. The use of multiple C2 domains and IPs, along with various evasion and persistence mechanisms, makes it a significant threat to targeted organizations. Organizations should implement robust security measures, including email filtering, endpoint detection and response (EDR), network monitoring, and regular security training for employees to mitigate the risk of such attacks.
