Complex attack chain
The early stages of a Dexphot infection involves numerous files and processes. During the
execution stage, Dexphot writes five key files to disk:


An installer with two URLs


An MSI package file downloaded from one of the URLs


A password-protected ZIP archive


A loader DLL, which is extracted from the archive


An encrypted data file that holds three additional executables that are loaded into system


processes via process hollowing
Except for the installer, the other processes that run during execution are legitimate system
processes. This can make detection and remediation more difficult. These legitimate system
processes include msiexec.exe (for installing MSI packages), unzip.exe (for extracting files from
the password-protected ZIP archive), rundll32.exe (for loading the loader DLL), schtasks.exe (for
scheduled tasks), powershell.exe (for forced updates). In later stages, Dexphot targets a few
other system processes for process hollowing: svchost.exe, tracert.exe, and setup.exe .
