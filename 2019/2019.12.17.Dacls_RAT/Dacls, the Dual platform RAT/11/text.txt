Configuration file .memcahce
The Linux.Dacls Bot configuration file is stored at $HOME/.memcache, and the file content is
0x8E20 + 4 bytes. If Bot cannot find the configuration file after startup, it will use AES encryption
to generate the default configuration file based on the hard-coded information in the sample. After
successful Bot communicates with C2, the configuration file will get updated.
Data structure
We define the data structure information of the configuration file as struct_global_cfg, which
stores the Bot operating parameters, C2 information, and plug-in information.

Decrypting the configuration file
After decrypting the configuration file, we can see some plain text information in it, for example:
session ID, version information, reconnection time for C2, C2 information, etc. After successfully
connecting to C2, the configuration file will be updated according to received C2 instructions,
such as adding new plugin information supported by the Bot, updated C2 information, etc.
