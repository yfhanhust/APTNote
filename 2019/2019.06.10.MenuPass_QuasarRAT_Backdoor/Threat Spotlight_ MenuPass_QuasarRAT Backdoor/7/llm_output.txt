The final payload assembly is stored as an encrypted file somewhere under the Microsoft.NET
Framework directory. The framework version is hardcoded in the loader binary in an encrypted form,
and in most samples set to “v4.0.30319” . The location is different per sample and the file name imitates
one of other the legitimate files found in the same directory. Example paths:
%WINDOWS%\Microsoft.NET\Framework\v4.0.30319\WPF\Fonts\GlobalSerif.CompositeFont.rsp
%WINDOWS%\Microsoft.NET \Framework\v4.0.30319\Microsoft.Build.Engine.dll.uninstall
The payload is decrypted and loaded in-memory as "Client". We have encountered two versions of the
Client: 2.0.0.0 and 1.3.0.0. They are similar, both having a version string in their configuration section
set to “2.0.0.0”:
