JavaScript dropper
The JavaScript dropper is a heavily obfuscated script embedded with base64 encoded
data of the other components of the attack. The JavaScript decodes and drops the
embedded files into the %TEMP% folder, including a batch script, a customized DLL
loader, an encrypted SugarGh0st payload, and a decoy document. It first opens the
decoy document to masquerade as legitimate action, then copies the legitimate rundll32
executable from the “Windows\SysWow64” folder into the %TEMP% folder. Finally, it
executes the batch script loader from the %TEMP% location and runs the customized
DLL loader. The JavaScript deleted itself from the file system afterward.
