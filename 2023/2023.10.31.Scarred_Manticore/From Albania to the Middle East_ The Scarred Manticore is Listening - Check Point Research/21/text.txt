Tunna-based web shell
One of the earliest samples related to the threat actor’s activity is based on a web shell
from Tunna, an open-source tool designed to tunnel any TCP communication over HTTP.
The Tunna web shell allows to connect from the outside to any service on the remote
host, including those that are blocked on the firewall, as all the external communication to
the web shell is done via HTTP. The IP and the port of the remote host are sent to the
web shell in the configuration stage, and in many cases, Tunna is mostly used to proxy
RDP connections.

1.1a is available on Github). The most significant change from the open-source version is
