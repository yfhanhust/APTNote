Initial access
Flax Typhoon achieves initial access by exploiting known vulnerabilities in public-facing
servers. The services targeted vary, but include VPN, web, Java, and SQL applications.
The payload in these exploits is a web shell, such as China Chopper, which allows for
remote code execution on the compromised server.
