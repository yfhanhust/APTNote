HrServ – Previously unknown web shell used in APT attack
In this report Kaspersky researchers provide an analysis of the previously unknown
HrServ web shell, which exhibits both APT and crimeware features and has likely been
active since 2021.
Asian APT groups target various organizations from a multitude of regions and industries.
We created this report to provide the cybersecurity community with the best-prepared
intelligence data to effectively counteract Asian APT groups.
