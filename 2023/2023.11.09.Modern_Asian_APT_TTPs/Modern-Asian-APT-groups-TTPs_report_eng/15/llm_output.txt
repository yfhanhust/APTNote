In mid-Autumn of 2021, Kaspersky experts detected a new ShadowPad malware campaign targeting one of the
national telecom companies of Pakistan. During a retrospective analysis of suspicious activity in the telecom
network, experts were able to detect an active backdoor of the ShadowPad family on computers of ICS
engineers and on automation systems. Based on the collected data, we can presume that the attack began no
later than the winter of 2021, and the attackers were active on the network for at least 11 months.
Detailed description
It is assumed that the initial infection occurred due to an exploit of a vulnerability in MS Exchange: CVE-202126855 — Exploit Public-Facing Application T1190. After gaining access to the system, the attackers installed
the Cobalt Strike backdoor, which was most likely used for the initial collection of information, including
authentication data. It is our presumption that this data was used for lateral movement through the network.
The mail server of the victim had a Web Shell in the form of a malicious DLL used by the attackers to gain
remote access to the server.

Communication with the C2 server
We detected a version of Cobalt Strike in which the malware does not connect to a C&C server. Instead, it
opens a network port and waits for a connection.
To work properly, this version of Cobalt Strike must receive binary shell code that will be executed
synchronously after it is received and copied to dynamic memory. Then Cobalt Strike uses the JMP command
to divert execution to the received shell code. To connect to Cobalt Strike, the victim must have an open public
IP address, or the attacker must be in the same subnet as the victim. For this connection, the attacker often
uses "pivoting" to route traffic that is not usually routed in normal conditions.

Output : 
This detailed report outlines a sophisticated cyber-espionage campaign targeting national infrastructure in Pakistan. The attack appears to be part of a broader campaign by an Advanced Persistent Threat (APT) group, likely originating from Asia, given the techniques used and previous sightings of similar malware in other countries like Afghanistan and Malaysia.

### Key Points:

1. **Initial Infection:**
   - **Backdoor Deployment:** The attackers deployed a backdoor to gain remote access.
   - **C2 Communication:** Initial communication with Command and Control (C2) servers was established using tools like ShadowPad.

2. **Lateral Movement:**
   - **Valid Account Credentials:** The attackers used legitimate user credentials, possibly obtained from the initial infection, to move laterally within the network.
   - **Remote Execution:** Commands were executed remotely on other machines to gather information and spread the infection.

3. **Reconnaissance:**
   - **System Discovery:** Tools like `quser`, `arp`, `netstat`, and `ping` were used to discover system owners, network configurations, and remote systems.
   - **Data Collection:** Sensitive data from user directories (e.g., Desktop, Downloads) was copied and archived.

4. **Credential Dumping:**
   - **SAM Registry Hive Dump:** The Security Account Manager (SAM) registry hive was dumped using `reg.exe`.
   - **LSASS Dump:** The Local Security Authority Subsystem Service (LSASS) process was dumped multiple times using tools like Mimikatz and Procdump to extract credentials.

5. **Data Exfiltration:**
   - **Archiving:** Collected data was archived using utilities like WinRAR.
   - **Exfiltration Scripts:** PowerShell scripts were used to automate the collection and exfiltration of data over C2 channels.
   - **Network Shares:** Network drives were mounted using compromised credentials to facilitate data transfer.

6. **Obfuscation:**
   - **Base64 Encoding:** Scripts and commands were often encoded in base64 to evade detection.
   - **Process Hollowing:** Malicious payloads were injected into legitimate processes (e.g., `svchost.exe`) to avoid suspicion.

### Techniques Used (MITRE ATT&CK):
- **T1033** - System Owner/User Discovery
- **T1016** - System Network Configuration Discovery
- **T1049** - System Network Connections Discovery
- **T1018** - Remote System Discovery
- **T1005** - Data from Local System
- **T1560.001** - Archive via Utility
- **T1003.002** - Security Account Manager (SAM) Dumping
- **T1078** - Valid Accounts
- **T1021.002** - SMB/Windows Admin Shares
- **T1119** - Automated Collection
- **T1020** - Exfiltration Over C2 Channel

### Summary:
This incident highlights the sophisticated nature of APT attacks, particularly those originating from Asia. The use of DLL side-loading and other obfuscation techniques indicates a high level of skill and intent to remain undetected for extended periods. The primary goal appears to be cyberespionage, with a focus on gathering critical or confidential data from national infrastructure.

### Recommendations:
- **Enhance Network Monitoring:** Implement advanced monitoring tools to detect unusual activity and lateral movement.
- **Strengthen Authentication:** Use multi-factor authentication (MFA) and regularly update credentials.
- **Regular Audits:** Conduct regular security audits and penetration testing to identify and mitigate vulnerabilities.
- **Employee Training:** Educate employees about phishing and other social engineering tactics to reduce the risk of initial infection.

By understanding these techniques, organizations can better prepare and defend against similar attacks in the future.
