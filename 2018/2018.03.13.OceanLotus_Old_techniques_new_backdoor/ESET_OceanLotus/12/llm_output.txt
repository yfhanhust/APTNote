A quick word on control flow obfuscation
Almost all of these components are obfuscated. The obfuscation is based on pairs of complementary
conditional jump instructions. Every form is used: ~~JZ/JNZ, JP/JNP, JO/JNO~~, etc, each pair jumping
to the same target. The sequence is interleaved with junk code, which makes use of the stack pointer,
but does not change the conditional flag’s value. This means it will always end up in the same branch.
This causes problems during decompilation due to the use of positive stack pointer values.

Moreover, some basic blocks push one address on the stack, then end with a ~~JMP/CALL~~ while other
basic blocks push two addresses then end with a ~~RET~~ instruction. The second push is the function
to call and the first one is the address of the next basic block to jump to. This creates basic blocks
with no parents.

Backdoor component: ~~rastlsc.exe~~ side-loading

executable files. The trick, here, is to take advantage of the library loading process of a legitimate

malicious behaviors look legitimate because these actions are made by the trusted executable process.

### Overview of the OceanLotus (APT-C-07) Backdoor

The backdoor, often attributed to the OceanLotus (also known as APT-C-07) group, is a sophisticated piece of malware designed for persistent and stealthy communication with a command-and-control (C&C) server. This document provides an in-depth analysis of the backdoor's components, behavior, and communication mechanisms.

### Components

#### 1. **Initial Infection Vector**
   - The initial infection vector can vary, but common methods include phishing emails, malicious attachments, or exploits targeting vulnerabilities in software.

#### 2. **Shellcode Execution**
   - Once the malware is executed, it typically starts with a shellcode that performs the necessary setup and persistence mechanisms.

#### 3. **Persistence Mechanisms**
   - The backdoor can use various techniques to ensure it runs on every system startup, such as:
     - Registry keys (e.g., `Run` or `RunOnce`).
     - Scheduled tasks.
     - Fileless persistence via registry or memory injection.

### Shellcode and Initial Execution

#### 1. **Shellcode**
   - The shellcode is responsible for loading the main payload and establishing initial communication with the C&C server.
   - It often includes a PE loader to load additional components into memory.

#### 2. **PE Loader**
   - The PE loader is used to load and execute the backdoor's main module in memory, ensuring that it remains undetected by traditional file-based scans.

### Communication

#### 1. **DNS Query for C&C Server IP**
   - The backdoor generates a custom subdomain using the computer name and version ID.
   - It then queries a DNS server to resolve this subdomain to an IP address.
   - Example domain generation:
     ```python
     letters = "ghijklmnop"  # domain_encoding_str
     hex_pc_name = pc_name.encode("UTF-16LE").encode("hex")
     s = ''

     for c in hex_pc_name:
         if 0x2f < ord(c) < 0x3a:
             s += letters[ord(c) - 0x30]
         else:
             s += c
     ```
   - Example domain: `niggmhggmeggmkggmfggmdggidggngggmjgg.ijhlokga.dwarduong[.]com`

#### 2. **TCP Communication**
   - The backdoor uses a classic TCP communication protocol over port 25123.
   - All data is encrypted using RC4 and compressed with LZMA.
   - Packet format: `[RC4 key (4 bytes)][encrypted data]`
   - Decrypted and decompressed data format:
     ```
     [dw:unknown][dw:unknown][dw:command number][dw:size of data][dw:unknown][dw:data]
     ```

#### 3. **HTTP/HTTPS Communication**
   - The `HTTPprov` library is used as a backup communication method.
   - It supports HTTP, HTTPS, and various proxy types (SOCKS5, SOCKS4a, SOCKS4).
   - URI generation algorithm:

### Detection and Mitigation

#### 1. **Network Monitoring**
   - Monitor for DNS queries to unusual subdomains.
   - Look for TCP traffic on port 25123 or HTTP/HTTPS requests with the custom URI format.

#### 2. **Endpoint Protection**
   - Use advanced endpoint protection solutions that can detect and block shellcode execution and memory injection techniques.
   - Regularly update and patch systems to mitigate known vulnerabilities.

#### 3. **Behavioral Analysis**
   - Implement behavioral analysis tools to detect anomalous activities, such as unexpected registry modifications or process creations.

By understanding the inner workings of this backdoor, organizations can better defend against and respond to potential threats from the OceanLotus group.
