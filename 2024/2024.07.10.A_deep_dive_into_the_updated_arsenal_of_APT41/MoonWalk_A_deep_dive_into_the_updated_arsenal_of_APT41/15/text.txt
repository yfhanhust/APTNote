Gathered environment information
This is the list of environment information gathered by MoonWalk and uploaded to
GoogleDrive as part of its initialization process.
Victim hash (FNV1a hash of the concatenation of the computer
name Config.rgbIDBytes and the machine’s GUID).
Windows major and minor version numbers
Windows build number
Computer name
User name
Executable path (full path to the current process’s executable file).
Impersonation status
CPU start time
IPv4 addresses
IPv6 addresses
