then decrypted using the following steps:

An HMAC is generated using the SHA1 hash algorithm from the password

The HMAC generated in step 4 is used as the key for AES, and the data from step 3

What is HMAC (Hash-based Message Authentication Code)?
A code and technique for ensuring the integrity and authenticity of a message using
a one-way hash function. It is widely used in secure communications where it is
necessary to verify the sender of the data or that the data has not been tampered
with in transit.
