Other spying modules: keylogger, screenshot tool and more
The user’s activity is monitored using several hooks. All of them gather the target’s data
independently of any C2 command. Keystrokes are encrypted using the RSA public key stored in
the configuration data and sent once every two seconds, or when moreа than 512 bytes are
recorded. These 512 characters also include left mouse button clicks (written as the “MSLBTN”
string) and Windows title bar texts. For clipboard content, the module calculates an MD5 hash
and if it changes, encrypts the clipboard content with the same RSA public key and then sends it.
In a separate thread, the Trojan takes a bitmap screenshot using the GDIPlus library, compresses
it with the LZNT1 algorithm, encrypts it using the key from the configuration data and sends it to
the control server. A screenshot will be taken of the target and sent anyway, independently of any
C2 command.
