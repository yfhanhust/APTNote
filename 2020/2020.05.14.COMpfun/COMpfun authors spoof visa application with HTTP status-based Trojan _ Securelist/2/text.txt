COMpfun authors spoof visa application with HTTP status- based Trojan
securelist.com /compfun-http-status-based-trojan/96874
By GReAT
You may remember that in autumn 2019 we published a story about how a COMpfun successor
known as Reductor infected files on the fly to compromise TLS traffic. If you’re wondering whether
the actor behind the malware is still developing new features, the answer is yes. Later in
November 2019 our Attribution Engine revealed a new Trojan with strong code similarities.
Further research showed that it was obviously using the same code base as COMPFun.
