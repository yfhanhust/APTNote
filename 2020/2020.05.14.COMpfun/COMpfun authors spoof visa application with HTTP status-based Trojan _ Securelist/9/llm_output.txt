The first GET request sent contains an ETag “If-Match” header that is built using data from its
decrypted configuration. ETags are normally used by web servers for caching purposes in order
to be more efficient and save bandwidth by not resending redundant information if an ETag value
matches. The implementation of ETags means the C2 may ignore all requests that are not sent
from its intended targets if they don’t have the required ETag value.
