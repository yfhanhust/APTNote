Opsec and targeted countries
The fact that this attacker decided to leverage cloud services and four different services — and
not their own infrastructure — is smart from an opsec point of view. It is hard for the targets to
identify legitimate and malicious traffic to cloud provider infrastructure. Moreover, this kind of
infrastructure uses HTTPS and the flow is encrypted that makes man-in-the-middle interception
more complicated for the defender. It is not the first time an attacker used only cloud providers.
