A password-protected PDF file is sent alongside an LNK shortcut that imitates a text file containing the pdf’s

2. When double-clicked the shortcut file sends an HTTP request to a remote server through Windows utility

5. The first stage payload gathers information about the infected system and sends them to the command and
control server.
6. CNC server responds with a Second Stage VBS payload, which will be saved under the %TEMP% directory.
7. Malware creates a shortcut file named ‘xBoxOne.lnk’ under the Startup directory as a means of persistence.
