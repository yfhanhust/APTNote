これは Microsoft Build Engine （ MSBuild ） ※10 を悪⽤した攻撃⼿⼝です。 .NET Framework ライン
タイムに標準で含まれる MSBuild は、 Visual Studio や .NET Framework のビルドエンジンであり、
独⾃の XML フォーマットファイル（プロジェクトファイル）を利⽤して .NET アプリケーション
を作成できます。 PoshC2 は、 EXE 、 DLL 、 BAT 、 JS など様々なフォーマット ※11 でペイロードを
作成でき、そのうちの 1 つにこの MSBuild で利⽤可能な XML ファイルがあります。

れた DLL ファイルが含まれていることが確認できます。

15 ）。
