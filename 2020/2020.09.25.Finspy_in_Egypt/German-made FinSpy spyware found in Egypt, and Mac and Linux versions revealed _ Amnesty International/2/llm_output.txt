Emergency Reconfiguration
FinSpy can be reconfigured via SMS, through the Java method org.xmlpush.v3.q.c.a() . When an SMS corresponding to
TlvTypeMobileTargetEmergencyConfig is received, FinSpy reconfigures itself by parsing the received payload. The following attributes can be
reconfigured:
TlvTypeConfigTargetPort: port number for the C&C proxy.
TlvTypeConfigSMSPhoneNumber: phone number for SMS based C&C communications.
TlvTypeMobileTrojanID: unknown purpose.
TlvTypeMobileTrojanUID: unknown purpose.
TlvTypeUserID: unknown purpose.
TlvTypeTrojanMaxInfections: unknown purpose.
TlvTypeConfigMobileAutoRemovalDateTime: implant self-destruction time.
TlvTypeConfigAutoRemovalIfNoProxy: implant self-destruct if C&C proxy is unavailable
TlvTypeMobileTargetHeartbeatRestrictions: conditions to avoid callbacks
TlvTypeMobileTargetHeartbeatEvents: events to trigger callbacks to the C&C
TlvTypeMobileTargetLocationChangedRange: trigger updates based on location changes
TlvTypeInstalledModules: list of implant features and their configuration (SMS log, call log, etc.)
and other unknown parameters

This is a detailed analysis of various versions and instances of the FinSpy malware, as reported by Amnesty International. Here’s a summary of the key points:

### Overview
- **FinSpy**: A sophisticated surveillance tool that has been used in targeted attacks.
- **Targets**: The report identifies multiple targets, including systems running Windows, macOS, Linux, and Android.

### Technical Analysis

#### Mac and Linux Versions
1. **Command Execution**:
   - The malware uses `dlopen` to load a shared library containing the payload.
   - It then calls specific functions to execute the payload in memory without writing it to disk.

2. **Payloads**:
   - The payloads are encrypted and decrypted at runtime.
   - They communicate with Command and Control (C&C) servers using HTTPS, often masquerading as legitimate traffic.

3. **Persistence**:
   - On macOS, the malware can create a LaunchAgent to ensure it runs on system startup.
   - On Linux, it may use cron jobs or systemd services for persistence.

#### Android Version
1. **Installation**:
   - The malware is often distributed via APK files that masquerade as legitimate apps.
   - It requests various permissions to access sensitive data and functionalities.

2. **Command Execution**:
   - The malware can execute commands received from the C&C server, including SMS interception, call recording, and location tracking.

3. **Reconfiguration**:
   - FinSpy can be reconfigured via SMS, allowing attackers to change C&C server details, self-destruction times, and other parameters.

#### Windows Version
1. **Backdoored WinRAR**:
   - The malware is embedded in a backdoored version of the WinRAR software.
   - The `___security_check_cookie_` function is patched to redirect execution to an obfuscated shellcode.

2. **Shellcode Execution**:
   - The shellcode makes an HTTP POST request to a C&C server to retrieve and execute additional payloads.
   - The payloads are decrypted in memory and run without being written to disk.

### Timeline
- **Certificate**: The certificate used to sign the Android APK was issued in May 2017, but the APK file was created on October 23, 2019.
- **WinRAR Backdoor**: The backdoored WinRAR version (5.71) was released in April 2019, and the backdoor was likely added between April and September 2019.
