TABLE 3: COMMANDS SUPPORTED BY VARIANTS TARGETED AT UKRAINIAN ENTITIES

|---|---|
|rexec|Download and execute a binary|
|lexec|Execute a shell command|

|chprt|Add / remove / set active command and control server|
