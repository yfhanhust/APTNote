afset, like setMFT is also used to timestomp files plus clean Microsoft Windows logs based on criteria�
(id, time) from the user. It also changes the PE build time and checksum. afset provides more granular
functionality to allow the user to set only certain timestamps on a file (sia, fna or both). To achieve the�
timestomping and log cleaning functions, afset uses the RawDisk driver with the same lengthy license
key.

attempted to write a randomly named file with a .sys extension to the local directory with the contents of�
the “ICONS” resource which is supposed to be the encoded RawDisk driver. However, it failed to
decode on execution. If the driver write had completed it would have registered as a service using the
same random driver name. Plus, it would have been used to obtain a handle to write the MFT record for
the target file to match either a user supplied file or by default the file�
“%SYSTEMROOT%\system32\tapi32.dll”.
